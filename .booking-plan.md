# Booking Page Plan

## Flow
1. Select session type → 
2. Calendly embed (pick date/time) → 
3. Payment (PhonePe QR + amount) → 
4. Confirmation screen

## Files to change
- `app/book/page.tsx` — full rewrite with multi-step flow

## Calendly
- Embed URL: `https://calendly.com/YOUR_USERNAME/SESSION_TYPE`
- User needs to replace with their actual Calendly link
- Calendly's free tier handles: timezone, availability, Google Meet, email reminders

## Payment
- QR: `/phonepe.jpeg` (already in public/)
- Manual verification: user pays via PhonePe, counsellor verifies in their app
- No gateway fees, no API integration
